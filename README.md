# Moment 2 i kursen DT210G, Fördjupad frontend-utveckling

## Moment 2 Frontend
Detta repo innehåller en fullständig Todo-applikation byggd med React frontend-ramverk, fastify backend-ramverk, och MySQL databasserver. Applikationen låter användaren att skapa todo-uppgifter genom att fylla Titeln(obligatorisk), beskrivning(valfri) samt välja status om det är 'Ej påbörjad', 'Pågående' eller 'Avklarad'. Efter lyckligt skapande får användaren sina todo-uppgifter listade i tabellform med möjligheter för uppdatering redan i tabellen samt borttagning.
